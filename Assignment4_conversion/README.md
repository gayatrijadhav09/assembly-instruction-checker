
# Little Endian Conversion Assignment

This assignment is written in C. It reads data declarations from an assembly input file and displays string characters in ASCII and hexadecimal formats. It also converts 32-bit numeric values into hexadecimal and Little Endian formats.

## Process
- Read declarations from input.asm.
- Identify strings in single or double quotes.
- Display ASCII and hexadecimal values of strings.
- Convert dd numeric values to hexadecimal.
- Display numeric values in Little Endian format.

## Files
- assembler_v2.c - C source code.
- input.asm - Input assembly program.
- README.md - Assignment documentation.
- Output.png - Program output screenshot.

## Compilation
gcc assembler_v2.c -o assembler_v2

## Execution
./assembler_v2

## Conclusion
This assignment demonstrates file handling, string processing, hexadecimal conversion, and Little Endian representation in C.
